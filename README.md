# English wordbook

A minimal, dark, fixed-viewport wordbook based on the supplied textbook photographs (pages 10–159). Text is paginated to fit the screen; questions and printed answers are presented individually. Open-ended exercises save responses locally. The URL records the current unit, section, question, answer, and page for browser history and direct links.

The source material was transcribed with OCR and selected manual corrections. Further proofreading against the photos is needed. No build step is required; GitHub Pages serves the repository root.
