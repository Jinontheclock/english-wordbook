# 단어, 차곡차곡

사진 72장에서 추출한 417개 영어 단어·표현을 공부하는 모바일 단어장입니다.

- 60개 단원, 원문 영어 풀이와 예문
- 직접 입력한 뒤 정답 확인, 오답 재시험, 랜덤 10문제
- 학습 상태는 기기별 localStorage에 저장
- 전체 사진의 OCR 텍스트 열람

https://Jinontheclock.github.io/english-wordbook/

빌드 과정 없이 main 브랜치 루트를 GitHub Pages로 배포합니다.

사진에서 추출한 텍스트에는 인식 오류가 남아 있을 수 있습니다. 학습 콘텐츠는 원본 교재에서 옮긴 것이며 별도의 오픈소스 라이선스를 부여하지 않습니다.
